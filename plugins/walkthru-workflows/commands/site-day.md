---
description: Draft today's daily site report (DPR) from raw site notes, or consolidate several sites' DPRs into an operations digest.
argument-hint: [site/project name and date, then notes or attached DPRs]
---
Invoke the `daily-site-report-digest` skill. Input: $ARGUMENTS

If one site's raw notes are given, use site-report mode and draft the DPR. If several DPRs are attached, use digest mode. Return the report, the issue/action table, the manpower comparison and next-day needs. Mark anything not reported as "Not reported"; never guess quantities or incident status.

A design-led, high-end contractor lives on contracts, tenders, monthly billing, submittals, transmittals and schedules. Most of that work already passes through Outlook, SharePoint and Excel, so Microsoft 365 is where Claude adds value first. The construction-specific tools (ePromis, P6, AutoCAD, KREO, PlanSwift) have no official Claude connection, so they feed Claude through exports.

The shared layer every employee gets

Set these up once for the whole company. Every role below builds on them.

Claude Team plan Ready

One organisation account with admin controls, shared Projects and central billing. Office add-ins and plugins need a paid plan. Check seat pricing and minimums on the pricing page.

Microsoft 365 connector Ready

Lets Claude search and read Outlook mail, calendar, SharePoint, OneDrive and Teams. A Microsoft Entra Global Administrator grants a one-time tenant consent. Write actions (drafts, uploads) need a second consent and must be switched on separately.

Excel, Word, PowerPoint add-ins Ready

Claude works inside the open workbook, document or deck. IT deploys all three from one AppSource listing in the Microsoft 365 admin center. A work or school M365 account is required.

Outlook add-in Beta

Summarise threads, draft replies and pull actions from the inbox. It has its own AppSource listing and admins deploy it separately.

Built-in file skills Ready

Claude creates and edits real .xlsx, .docx, .pptx and .pdf files in chat with no setup. It also reads scanned PDFs and drawing sheets.

Claude Desktop + Cowork plugins Adapt

Anthropic's free, open-source knowledge-work plugins bundle role skills and commands. They run in Claude Desktop. Their default connectors (Slack, Gmail, Notion) don't match WalkThru, so swap them for Microsoft 365 using the cowork-plugin-customizer.

Arabic: Claude drafts and translates in Arabic and English. That covers bilingual HR letters, authority correspondence and client letters at no extra cost.

Custom skills worth building

The official plugins are generic. These WalkThru-specific skills would carry the most weight. Build them with Anthropic's skill-creator and share them across the organisation.

construction-contract-review

Risk checklist for FIDIC-style and bespoke UAE contracts and subcontracts: payment, retention, LDs, EOT, variations, termination.

payment-application-check

Monthly IPA reconciliation: measured work, approved and pending variations, retention, advance recovery.

tender-bid-summary

Bid/no-bid brief from tender documents: scope, programme, bonds, insurances, key risks.

doc-control-standards

WalkThru numbering rules, transmittal format and register checks.

site-reporting

Company templates for MOM, weekly progress reports and look-aheads.

bilingual-letters

English/Arabic letterhead templates for HR, authorities and clients.

Rollout order

  1. Choose the plan and seats

    Confirm a company-managed plan and seat count with MD/GM/IT for the pilot; plan availability must be checked before purchase. Set up the organisation and invite users.

    Owner: MD / GM, with IT

  2. Grant Microsoft 365 consent

    The Entra Global Administrator approves the connector for the tenant. Start with read access; enable write tools later if the document controller needs them.

    Owner: IT / M365 admin

  3. Deploy the Office add-ins

    Push Excel, Word and PowerPoint from the Microsoft 365 admin center. Add Outlook (beta) for leadership and coordinators first.

    Owner: IT / M365 admin

  4. Install Desktop and the role plugins

    Finance, legal, HR, operations, productivity, enterprise-search, data. Swap their connectors to Microsoft 365 and remove skills that don't apply.

    Owner: IT, with each department head

  5. Build the custom construction skills

    Start with contract review and payment applications. Those two save the most hours.

    Owner: Commercial Manager, with an AI lead

  6. Pilot the community tools (optional)

    DWG reader and p6xer on one test machine, after IT review. Keep data on local machines.

    Owner: IT, Planning and Technical Managers

Ground rules: staff use company accounts only, never personal ones, for client or project data. A person checks every figure, clause reference and legal point before it leaves the company.
